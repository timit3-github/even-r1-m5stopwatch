# 検証範囲

## 実機で報告された結果

環境: ESP-IDF 5.5.1、iPhoneのEvenアプリ2.3.2、G2 2.3.2.14。

| 対象 | 結果 |
|---|---|
| Evenアプリのペアリング | 成功 |
| G2接続、購読、接続維持、コンソール全操作 | 成功 |
| StopWatch G1/G2操作とshort→long | 成功 |
| StopWatch G2保持中up繰り返し | 成功 |
| StopWatchタッチ操作 | 0.2.9で成功 |
| 再起動後G2再接続 | 数分後に復帰する事例あり。遅延原因・長期安定性は未確定 |
| バッテリー残量のアプリ表示 | 未確認 |

純正R1を使わずに実機試験しています。純正R1と全動作が同一かを検証したものではありません。
現在の動作から過去の失敗原因や、別バージョンの互換性を断定していません。

## ホストテスト

`sh tests/run_host_tests.sh`で、C11 -Wall -Wextra -Werrorを使って次を検証します。

- wire: 固定MODBUS/compact CCITTフレーム、CRC、断片化、破損、順序・長さ制限。
- legacy: コマンド応答、操作通知、専用type9、未知コマンド、ターゲット比較。
- inputs: タップ/二度押し/保持、500ms繰り返し、設定変更、デバウンス、解放、時刻折返し。
- battery: 電圧換算境界、平滑化、異常値と時刻の保持、不正換算範囲。
- touch: 座標復号、異なる位置の二度押し、保持/メニュー、閾値、横移動除外、1接触1スワイプ、リセット。

公開用整理後に全テストが通過しています。整理でGPIOやBLE処理の仕様は変更していません。
ホストテストは電気的なI2C動作や画面表示を検証するものではありません。
