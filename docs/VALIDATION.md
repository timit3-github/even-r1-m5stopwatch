# 検証範囲

## 作者実機で確認した結果

環境はM5Stack StopWatch、ESP-IDF 5.5.1、iPhoneのEvenアプリ2.3.2、G2 2.3.2.14です。

| 対象 | 結果 |
|---|---|
| Evenアプリのペアリング、G2操作、コンソール全操作 | 成功 |
| G1の各タップ操作とshort→long | 成功 |
| G2短押しdown、長押しup、保持中500ms周期のup | 成功 |
| タッチの各タップ操作と上下スワイプ | 0.2.9で成功 |
| バッテリー駆動で無操作60秒後のタッチ停止 | 成功 |
| ボタンによるタッチを含む操作再開 | 成功 |
| 待機からの最初の二度押し | 成功 |
| USB接続中の10分以上の待機 | 自然切断なし |
| USB抜去後のVINロック解除・Light-sleep、再接続後の再取得 | 成功 |
| 約21時間の長時間試験 | G2切断・ホストリセット0、終了時も再接続なしでボタン・タッチ操作成功 |
| 電圧推定残量のEvenアプリ表示とG2ダッシュボードの電池アイコン | 残量に応じた表示変化を確認。残量精度は未確認 |
| 再起動後G2再接続 | 数分後に復帰する事例あり。原因・長期安定性は未確定 |

省電力結果はv0.3.1と同じ動作設定を使ったリリース前構成（旧MODE3）で確認しました。
検証用コードを整理したv0.3.1そのものの実機確認は未実施です。
長時間試験はEvenアプリの低電力モードOFF、G2を途中で充電しない条件です。
試験区間のLight-sleep滞在率は約72％でした。全リンク切断4回、待機復帰6回の増加があり、完全無操作の試験とは区別します。
実機の通知文字列は2.9.9.9999で、v0.3.1のR1_APP_VERSION既定値も同じです。
詳細は[POWER.md](POWER.md)を参照してください。

純正R1を使わずに試験しています。純正R1との全動作の一致や、別バージョンの互換性を確認したものではありません。

## ホストテストとビルド

`sh tests/run_host_tests.sh`でC11 -Wall -Wextra -Werrorを使って次を検証します。

- wire: フレーム、CRC、断片化、破損、順序・長さ制限。
- legacy: コマンド応答、操作通知、type9、未知コマンド、ターゲット比較。
- inputs: タップ・二度押し・保持、500ms繰り返し、デバウンス、解放、時刻折返し。
- battery: 電圧換算、平滑化、異常値・時刻の保持、不正換算範囲。
- touch: 座標復号、タップ・保持、スワイプ境界、移動取消、リセット。
- idle: 待機判定、未完了操作の保留、ボタン復帰、最初のG1/G2押下、時刻折返し。
- usb_power: VINヒステリシス、低電圧確認、読み取り失敗時の保持、抜去後の解除、再接続。

v0.3.1の全ホストテストは通過しています。WSL2上のESP-IDF 5.5.1で、新規sdkconfigからのESP32-S3ビルドも成功しています。
ホストテストとビルドは、電気的なI2C動作や実機の操作・接続安定性を検証するものではありません。

## 未実装・未検証

- 完全無操作での長時間試験、復帰直後の全操作、繰り返し接続と長期安定性。
- 電圧推定残量の精度、充電中・満充電状態の判定、実測平均電流。
- 生体センサー、DFU、工場機能、独自アルゴリズム認証、ディスプレイ描画。
- 純正R1と同一の電源制御・接続ポリシー、他のアプリ/G2バージョンとの互換性。
- USB切断の根本原因。VINロックによる回避は実機確認済みです。
